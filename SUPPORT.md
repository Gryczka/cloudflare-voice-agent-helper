# Support

> **This project is shared as a reference sample.** It is not actively
> maintained, and there is no guaranteed response time. Support is
> best-effort via [GitHub Issues](../../issues) — please don't expect a
> fast turnaround.

## Getting Help

- **Documentation**: start with the [README](README.md) — it covers
  architecture, setup, customization, and the cost-guard quotas.
- **Questions**: open a [GitHub Issue](../../issues) with the `question`
  label, or use [GitHub Discussions](../../discussions) if enabled on this
  repository.
- **Bugs**: file a
  [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md).
- **Feature ideas**: file a
  [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md).

## Cloudflare Product Support

This demo builds on several Cloudflare products. For questions about the
underlying platforms themselves (rather than this sample app), the official
docs are the best starting point:

- [Workers](https://developers.cloudflare.com/workers/)
- [Durable Objects](https://developers.cloudflare.com/durable-objects/)
- [Agents SDK](https://developers.cloudflare.com/agents/)
- [Workers AI](https://developers.cloudflare.com/workers-ai/)
- [Rate Limiting bindings](https://developers.cloudflare.com/workers/runtime-apis/bindings/rate-limit/)
